## 🧰 Troubleshooting & Common Questions

### ❓ Nothing happens when I click the Apply button?

- Make sure the game is running and you are loaded into a save file. Some features only work when the game is active. 
- Check if you are running the trainer as **Administrator**. Right-click the trainer `.exe` file, select **Properties**, then **Compatibility**, then check **"Run this program as an administrator"**.

### ❓ The game crashes when I add an item.

- Try adding items one at a time (not a huge stack all at once. ) Then save your game normally. If it still crashes, restore your last restore point and add the item again more slowly.
